# 德文猫正文配图案例库

这套案例库用来展示“如何把抽象观点变成由德文猫推动的物理动作”。案例不是固定模板：面对新的文章，应保留思考方式，重新设计物件、动作和空间关系。

## 使用原则

1. 先找到文章中唯一需要解释的认知动作。
2. 把抽象概念改写成一个可见的物理变化。
3. 让德文猫亲手完成导致变化的关键动作。
4. 标注只指出核心状态，不复述整段文章。
5. 同一篇文章不要连续复用相同物件或动作。

## A 组：信息与判断

### A1. 信息滤网

- **适用观点：** 信息越多不等于判断越好，真正重要的是过滤噪声。
- **物理隐喻：** 一台手摇圆形筛选机，混杂纸片从一侧涌入，有效信号落入托盘，噪声从侧口排出。
- **德文猫动作：** 一手观察筛面，一手转动摇柄，主动控制筛选力度。
- **构图建议：** 左侧信息流，中部筛选机，右侧德文猫，下方结果托盘；保留大面积白底。
- **短标注：** `信息流`、`过滤`、`噪声`、`有效信号`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“信息越多不等于判断越好，关键在过滤噪声”生成一张正文配图。
让德文猫亲自操纵一个低科技筛选装置，画面白底、清爽、少字。
```

预览：[01-information-filter.png](images/01-information-filter.png)

### A2. 选题雷达台

- **适用观点：** 好选题来自真实信号的交叉验证，不来自关在房间里猜。
- **物理隐喻：** 三个方向传来的微弱波纹，在一台旧式雷达盘上形成唯一重合亮点。
- **德文猫动作：** 调整雷达角度，同时用铅笔圈出“用户问题、变化、亲历”三种信号的交点。
- **构图建议：** 德文猫与雷达台位于中部，三束细波纹从远处进入，不画复杂数据面板。
- **短标注：** `真实问题`、`新变化`、`亲历`、`交点`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“好选题是用户问题、外部变化和个人经历的交点”设计一张图。
不要画维恩图，让德文猫通过一个旧式观察装置找到交叉信号。
```

### A3. 用户问题采样站

- **适用观点：** 不要只看热度，要回到用户说过的真实原话。
- **物理隐喻：** 嘈杂风中漂来许多气泡，德文猫用采样瓶接住带有真实问题的小气泡，其余自然飘走。
- **德文猫动作：** 对照小本子核验样本，把确认过的问题贴上日期标签。
- **构图建议：** 气泡分散在左侧，德文猫半蹲采样，右侧只有三个已编号的小瓶。
- **短标注：** `原话`、`场景`、`反复出现`、`待验证`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“选题研究要收集用户真实问题，而不是只追热榜”生成一张图。
让德文猫像现场研究员一样采样和核对，不要画搜索界面。
```

## B 组：验证与迭代

### B1. 小实验水道

- **适用观点：** 不要一开始就做庞大计划，先用最小实验获得真实反馈。
- **物理隐喻：** 巨大的计划纸卷在后方，德文猫只撕下一小角折成纸船，先放进窄水道测试。
- **德文猫动作：** 亲手把纸船放入水中，观察航迹并准备在下游调整。
- **构图建议：** 左后方是淡化的大计划，前景是一条细水道，动作集中在德文猫双手。
- **短标注：** `大计划`、`先下水`、`再调整`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“别先做一艘大船，先折一只纸船下水”生成一张正文配图。
```

预览：[02-small-test.png](images/02-small-test.png)

### B2. 失败校准台

- **适用观点：** 失败不是结论，而是帮助下一次动作更准确的测量值。
- **物理隐喻：** 三个歪斜落点被送入机械校准台，指针根据偏差慢慢回到中心。
- **德文猫动作：** 用扳手微调刻度，再发射一个更小的测试球验证结果。
- **构图建议：** 不画成功/失败对勾；用“偏差—调整—新落点”表达迭代。
- **短标注：** `偏差`、`调整`、`再试一次`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“失败提供的是校准数据，不是自我否定”设计一张图。
用低科技测量装置和一次新的小测试表达，不要画情绪海报。
```

### B3. 最小闭环邮局

- **适用观点：** 真正的第一版不是做完产品，而是完成一次从需求到交付再到反馈的闭环。
- **物理隐喻：** 一间只有三个窗口的小邮局：收件、加工、回信；一封信绕一圈后带回读者批注。
- **德文猫动作：** 从斜挎包取出第一封信，盖章后亲自送进回流槽。
- **构图建议：** 三个窗口围成松散弧形，避免正式流程箭头；用信封轨迹表示闭环。
- **短标注：** `真实需求`、`第一次交付`、`收到反馈`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“第一版要先跑通需求、交付和反馈的最小闭环”生成一张图。
不要画标准流程图，改成德文猫亲手运营的小邮局。
```

## C 组：积累与成长

### C1. 复利绳索

- **适用观点：** 每天微小的稳定行动，会逐渐形成可以拉动结果的复利力量。
- **物理隐喻：** 每日细线经过手摇装置被拧成粗绳，最终连接一个有重量的结果。
- **德文猫动作：** 持续转动绞线器，把一天天的微小投入并入同一根绳索。
- **构图建议：** 从左到右呈现“细线—合股—粗绳—结果”，但保持物理场景而非流程图。
- **短标注：** `每天一点`、`持续积累`、`复利结果`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“持续行动的复利不是曲线，而是每天把力量拧进同一根绳子”生成一张图。
```

预览：[03-compounding-rope.png](images/03-compounding-rope.png)

### C2. 内容种子温室

- **适用观点：** 一条好内容不是发布后结束，而是可以持续长成案例、问答、视频和产品线索。
- **物理隐喻：** 一颗“核心观点”种子长出不同枝条，每根枝条只结一种果实。
- **德文猫动作：** 修剪重复枝条，把读者反馈做成养分添回土壤。
- **构图建议：** 小型玻璃温室只露出轮廓，不画复杂生态；主体是一株结构清晰的内容植物。
- **短标注：** `核心观点`、`读者反馈`、`继续生长`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“一条内容发布后，还能从反馈里继续长出新的内容和产品线索”设计一张图。
让德文猫照料一座极简内容温室。
```

### C3. 知识抽屉地图

- **适用观点：** 收藏不是知识管理，能在需要时找到并重新使用才是。
- **物理隐喻：** 许多无标签抽屉组成一面墙，德文猫拉出其中三个，在桌面拼成一张可行动的地图。
- **德文猫动作：** 给抽屉贴用途标签，并把零散卡片连接成当前任务路径。
- **构图建议：** 抽屉墙只画局部，焦点放在桌面上正在形成的地图。
- **短标注：** `找到`、`连接`、`重新使用`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“知识管理不是收藏，而是在需要时找到、连接和重新使用”生成一张图。
不要画知识库 UI，让德文猫操作真实抽屉和纸卡。
```

## D 组：关系与协作

### D1. AI 是风，人来掌舵

- **适用观点：** AI 能放大速度和能力，但目标、判断与责任仍需要人掌握。
- **物理隐喻：** 一阵写着 AI 的大风推动小船，远处有多个浮标，只有一个是真正目的地。
- **德文猫动作：** 看罗盘、划桨、调整航向，而不是被风随意吹走。
- **构图建议：** 左侧风力，中部德文猫与船，右侧目标浮标；保持开阔白色水面。
- **短标注：** `AI 是风`、`人掌舵`、`方向`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“AI 是风，但方向盘仍在人手里”生成一张正文配图。
```

预览：[04-human-ai-steering.png](images/04-human-ai-steering.png)

### D2. 信任拼图门

- **适用观点：** 信任不是靠口号建立的，而是由一块块可验证证据组成的通行条件。
- **物理隐喻：** 一扇没有把手的门，只有把案例、过程、结果三块异形证据放对位置，门才会打开。
- **德文猫动作：** 对照实际记录检查最后一块拼图，再亲手嵌入门中。
- **构图建议：** 门不画成宏大城堡；聚焦“最后一块证据被放入后出现缝隙光”。
- **短标注：** `真实案例`、`过程透明`、`结果可验`、`信任`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“信任不是说服，而是一块块可验证证据拼出来的”生成一张图。
不要画桥，让德文猫完成一扇证据拼图门。
```

### D3. 注意力闸门

- **适用观点：** 注意力管理不是更努力吸收，而是主动决定什么能进入今天。
- **物理隐喻：** 大量彩色请求像水流涌向一个小闸门，闸门后只有三条清晰水渠。
- **德文猫动作：** 根据今日目标转动闸门，只放行与目标相关的三股水流。
- **构图建议：** 德文猫站在闸轮旁，不画待办列表；通过水量变化展示选择。
- **短标注：** `都想进来`、`今日目标`、`主动放行`
- **调用示例：**

```text
Use $huahai-cat-illustrations 为“注意力管理的核心不是接住更多，而是决定什么不进入今天”生成一张图。
让德文猫操作一个低科技闸门。
```

## 如何扩展案例库

新增案例时，至少改变下面三项中的两项：

- 主要物件：不要连续使用同一台机器、同一种容器或同一条路线。
- 核心动作：筛选、测量、连接、修补、递交、种植、记录应交替出现。
- 空间关系：左右转换、中心装置、前后景、环形回流、小分镜应根据观点选择。

一个新案例只有在“德文猫的动作能解释观点”时才值得收录。单纯更换标题、颜色或道具，不算新的案例。
