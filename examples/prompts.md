# 德文猫 Prompt 示例库

下面这些指令可以直接复制到 Codex 中使用。把占位内容替换成你的文章、文件路径、图片或观点即可。

## 只做配图规划

```text
Use $huahai-cat-illustrations 先不要生图。
请分析下面这篇文章哪里真正值得配图，输出 5 张左右的 shot list。
每张写清楚：
- 放在哪个段落后
- 图的主题
- 唯一核心意思
- 物理隐喻与构图类型
- 德文猫在图里做什么
- 主要物件
- 建议中文短标注

<粘贴文章>
```

## 直接生成文章正文配图

```text
Use $huahai-cat-illustrations 为下面这篇中文文章设计并生成 4 张德文猫正文配图。
要求：16:9 横版、白底彩色手绘、大量留白、一图一事。
德文猫必须承担改变结果的关键动作，不要做成角色海报或 PPT 信息图。

<粘贴文章>
```

## 长文配图策略

```text
Use $huahai-cat-illustrations 给这篇长文做配图策略。
不要按段落平均配图，只挑认知锚点：核心判断、输入输出、关键转折、常见误区、验证动作和承接路径。
规划 6–8 张，先输出 shot list，不生成图片。

<粘贴文章>
```

## 为单个观点生成一张图

```text
Use $huahai-cat-illustrations 为这个观点生成一张 16:9 正文配图：

“信任不是喊出来的，而是一块证据一块证据拼出来的。”

请重新发明一个低科技物理隐喻，让德文猫亲手完成关键动作。
中文标注最多 5 处，每处尽量不超过 6 个字。
```

## 从案例库选一个方向再原创

```text
Use $huahai-cat-illustrations 参考 examples/case-library.md 中“选题雷达台”的思考方式，
为下面这段内容重新设计一张图。只借鉴“如何把抽象判断变成动作”，不要复刻雷达、构图或标注。

<粘贴内容>
```

## 生成并插入 Obsidian / Markdown

```text
Use $huahai-cat-illustrations 为这个 Markdown 文件生成 4 张正文配图。
把图片保存到 assets/<article-slug>-devon-cat/，按 01-topic-name.png 顺序命名。
实际检查图片后，把相对 Markdown 图片链接插入对应认知锚点后，不要改动文章其他文字。

文件：<绝对路径>
```

## 将旧角色插画重新设计为德文猫

```text
Use $huahai-cat-illustrations 重新设计这张旧角色正文配图。
保留它想表达的核心观点，但不要贴图换脸，也不要照抄旧构图。
请让德文猫成为真正推动结构运转的人，并保持白底彩色手绘风格。

图片：<图片路径>
```

## 修正角色漂移

```text
Use $huahai-cat-illustrations 编辑这张图。
保持核心构图和动作，只根据内置角色三视图修正德文猫：奶白毛色、大尖耳、蓝眼、绿色米白夹克、卡其工装裤、绿白鞋、黑色斜挎包和一条卷尾。
删除多余肢体、重复尾巴和参考图背景污染。
```

## 去掉错误文字或多余标题

```text
Use $huahai-cat-illustrations 编辑这张图。
只删除左上角的“流程图”标题和错误标注“有效信号号”，用相同白色背景自然补齐。
其他角色、物件、标注、构图和比例保持不变，不要新增内容。
```

## 生成一组风格样片

```text
Use $huahai-cat-illustrations 生成 5 张不同主题的德文猫正文配图样片。
主题分别覆盖：信息过载、用户验证、内容复利、人机协作、信任建立。
每张单独生成，不要拼图；构图和主要物件不能重复。
```

## 完全随机生成

```text
Use $huahai-cat-illustrations 随机选择 4 个适合知识型创作者的抽象主题，
为每个主题重新发明一个低科技物理隐喻，并分别生成德文猫正文配图。
不要先问我选题，每张独立输出。
```
